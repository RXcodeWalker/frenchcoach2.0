# Junior illustrations

Drop a picture in this folder and it replaces the drawn fallback with no code change
(`features/junior/art/JuniorArt.tsx`, `assetUrlFor`). The file name (before the extension) is the
picture id below. `.png`, `.webp`, `.jpg` or `.svg`; **transparent background, square, 512×512,
subject centred with a little margin.** Keep each under ~80 KB (export as WebP).

## One style for all of them

> Cute flat vector sticker illustration for a children's language-learning app, ages 8–13.
> Thick soft rounded shapes, no outlines (or a very thin darker outline of the same hue), flat
> colour with one gentle shade tone, a tiny white highlight. Friendly, slightly chunky, simple.
> Palette: warm orange, violet `#7C43E6`, sunny yellow, sky blue, leaf green, coral pink.
> Transparent background, centred, no text, no shadow, no border. Square, 512×512.

Generate them in one batch/conversation so the style stays consistent; ask for "same style as the
previous image" for each new one.

## Léo (the fox guide) — `leo-<state>.png`

Same character in five poses: orange fox, cream muzzle and chest, violet scarf, big friendly eyes,
pointy ears with pink inner ear. Head-and-shoulders, front view.

- `leo-happy` — gentle smile
- `leo-listening` — ears tall and turned out, calm open mouth, small sound-wave arcs beside him
- `leo-celebrating` — eyes closed in joy, mouth wide open, small stars around him
- `leo-curious` — one eyebrow raised, small round mouth, head tilted
- `leo-thinking` — eyes looking up and aside, flat mouth, three small thought dots

(His sunglasses are drawn in code over the face; a painted Léo does not wear them yet.)
